# DIGITAL教材

予備校のPDFテキストを読むための、個人用のPDFビューア(PWA)です。
ブラウザで開いてホーム画面に追加すると、アプリのように使えます。

https://taichi-tools.github.io/bunko/

- 本棚・検索(行をまたぐ語もヒット)・目次・見開き・拡大・文字のコピー
- オフラインで使えます
- PDFは各端末の中にだけ保存され、このリポジトリやサーバーには含まれません

個人が作った非公式のツールで、予備校とは関係ありません。

## 使っているもの

- [PDF.js](https://mozilla.github.io/pdf.js/)(Mozilla、Apache License 2.0)
